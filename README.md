# 社会学チューブ

社会学に関係するYouTube動画（日本語・英語）を毎日21時ごろに自動で記録し、
スマホで見られる画面にまとめます。

- **今日**：24時間で再生が伸びた動画のランキング（言語・分野・長さで絞り込み）
- **チャンネル**：登録者数と再生の伸びをチャンネルごとに比較
- **分野**：8分野のうち、どの分野の動画が伸びやすいかを比較

## しくみ

1. GitHub Actions が毎日 20:40（日本時間）に `scripts/collect.py` を実行
2. YouTube Data API で8分野×日本語・英語の検索をし、直近7日に投稿された動画を見つける
3. 見つけた動画は投稿から30日間、毎日の再生数・高評価数・コメント数を記録。チャンネルの登録者数も記録
4. 記録は `data/` に、画面用の集計は `docs/data/summary.json` に保存
5. GitHub Pages が `docs/` を公開し、スマホで見られる

APIの使用量は1日約3,400ユニットで、無料枠（1日10,000）に収まります。

## 設定を変えたいとき

分野・検索語・追跡日数は `scripts/config.py` にまとまっています。

## 注意

- 登録者数はYouTubeの仕様で上3桁に丸められています。小さな増減は0に見えることがあります
- 分野の判定は検索語と言葉の一致による自動判定です
- 公開ページと記録データは誰でも見られます（YouTubeで公開されている数字だけです）。APIキーはGitHubの「Secrets」に入れるので公開されません
